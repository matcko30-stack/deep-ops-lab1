## 3. Що зроблено — коротко
Сайт **DEEP OPS** на тему «довготривалий бойовий дайвінг: морські підрозділи світу та їхнє спорядження». 5 сторінок, єдиний зовнішній CSS, без фреймворків, адаптивний. Методичка дозволяє тему на вибір студента («Моє хобі» або інша).

**Чому така тема (для пояснення у звіті):** мене цікавлять морський спецназ і спорядження для роботи під водою та вночі; тема нестандартна, дає багато фактичного контенту для всіх трьох типів блоків (текст, списки, таблиці з датами, характеристиками й порівняннями) і добре підходить для галереї спорядження. Ця ж тема продовжується в лабах 2 (інтернет-магазин спорядження і ПНВ), 10 (закритий Telegram-клуб) і 11 (магазин WayForPay) — як єдиний проєкт DEEP OPS.

**Важливо для звіту:** сайт інформаційний, не пов'язаний з жодним підрозділом (про це є примітка на сайті); емблеми й символіка підрозділів не використовуються — усі ілюстрації власні. Дані про підрозділи — з відкритих джерел (див. літературу).

### Взаємозв'язок сторінок
- На кожній сторінці меню з посиланнями на всі 5 сторінок.
- Додатково — внутрішні посилання в тексті: index → units («Підрозділи»), units → gallery, gallery → tips, tips → contacts, contacts → tips.
- Усі посилання відносні (`href="tips.html"`), сайт відкривається локально без помилок (перевірено автоматично: усі файли й зображення завантажуються, битих посилань немає).

### Оформлення (css/styles.css)
- **Палітра з 5 кольорів** (CSS-змінні) — «нічне море + зелений нічного бачення»: `#0b1d2a` темно-синій (навігація, футер), `#12384a` глибина (шапка, посилання), `#158f57` зелений (акценти, hover), `#e6eef0` світлий сіро-блакитний (фон блоків), `#ffffff` білий (фон сторінки).
- **Шрифт:** Arial, Helvetica, sans-serif.
- **Ширина контенту:** `max-width: 1200px; margin: 0 auto;`.
- **Розкладка блоків:** CSS Grid, 3 колонки (`grid-template-columns: repeat(3, 1fr)`).
- **Адаптивність (media queries):**
  - `≤ 1024px` — 2 колонки, галерея 2×;
  - `< 768px` (`max-width: 767px`) — блоки йдуть вертикально в 1 колонку, меню центрується й переноситься, футер у стовпчик.
- **Hover-ефекти:** посилання змінюють колір на зелений; пункти меню отримують зелений фон; кнопка форми змінює колір.
- Таблиці — «зебра» (`nth-child(even)`), заголовки на темно-синьому фоні.
- Код прокоментований: в HTML (`<!-- Початок шапки -->`, `<!-- Блок 1: … -->` тощо) і в CSS (`/* ---------- Шапка (Header) ---------- */`).
- Фреймворків немає — чистий HTML5 + CSS3.

## 5. Фрагменти коду для звіту (можна вставити як є, моноширинним шрифтом)

**Шапка і навігація (HTML):**
```html
<!-- Початок шапки -->
<header class="site-header">
  <div class="container header-inner">
    <a href="index.html" class="logo">
      <img src="images/logo.svg" alt="Логотип сайту DEEP OPS" width="64" height="64">
      <span class="logo-text">
        <span class="site-name">DEEP OPS</span>
        <span class="slogan">Довготривалий бойовий дайвінг: підрозділи та спорядження</span>
      </span>
    </a>
  </div>
</header>
<!-- Початок навігації -->
<nav class="site-nav" aria-label="Головне меню">
  <div class="container">
    <ul>
      <li><a href="index.html" class="active" aria-current="page">Головна</a></li>
      <li><a href="units.html">Підрозділи</a></li>
      <li><a href="gallery.html">Спорядження</a></li>
      <li><a href="tips.html">Поради</a></li>
      <li><a href="contacts.html">Контакти</a></li>
    </ul>
  </div>
</nav>
```

**Сітка з трьох колонок і адаптивність (CSS):**
```css
.container { max-width: 1200px; margin: 0 auto; padding: 0 20px; }

.content {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

@media (max-width: 1024px) {
  .content { grid-template-columns: repeat(2, 1fr); }
}

/* Мобільні (< 768px): блоки розташовуються вертикально */
@media (max-width: 767px) {
  .content { grid-template-columns: 1fr; }
}
```

**Шапка фіксованої висоти та hover меню (CSS):**
```css
.site-header { height: 100px; background-color: var(--sea); }
.site-nav ul { display: flex; flex-wrap: wrap; list-style: none; }
.site-nav a:hover { background-color: var(--accent); color: var(--white); }
```

## 7. Висновки (тези, розгорни в 1–1,5 сторінки)
- Навчився створювати багатосторінковий сайт із семантичною структурою HTML5 (`header`, `nav`, `main`, `section`, `footer`).
- Зрозумів переваги зовнішнього CSS: одна зміна стилю застосовується до всіх 5 сторінок; CSS-змінні спрощують керування палітрою.
- Освоїв CSS Grid і Flexbox для колонок та меню, media queries для адаптивності.
- Навчився будувати таблиці (`caption`, `thead`, `tbody`, `scope`) і форми (`label for`, типи `input`, `select`, `textarea`, `required`).
- **Труднощі:** довгий текст і таблиці у вузьких колонках на планшетах (вирішено переходом на 2 колонки при ≤ 1024px); галерея з 8 зображень не вміщалась у колонку (зроблено блок на всю ширину через `grid-column: 1 / -1`); підбір однакової висоти карток галереї.
- **Труднощі зі змістом:** перевірка фактів про підрозділи (дати створення, бази) — використовував лише відкриті джерела; частина підрозділів засекречена, тому інформація загальна.
- **Пропозиції:** додати JavaScript для валідації форми, підключити серверну обробку форми, опублікувати сайт на GitHub Pages, перетворити сайт на інтернет-магазин спорядження (це зроблено в лабі 2).
