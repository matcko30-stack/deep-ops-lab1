# Лабораторна робота №1 — статичний сайт DEEP OPS (HTML + CSS)

**Студент:** Мацько Богдан Володимирович, група 3-2з (ДТЕУ, спеціальність 122 «Комп'ютерні науки»).

Інформаційний сайт на 5 сторінок, лише HTML і CSS.

Після публікації через **GitHub Pages** сайт відкривається за адресою `https://matcko30-stack.github.io/deep-ops-lab1/`.

## Як відкрити
- Онлайн: GitHub Pages (див. адресу вище).
- Локально: завантажте репозиторій (Code → Download ZIP), розпакуйте й відкрийте `index.html` у браузері.

## Структура
- `index.html`, `units.html`, `gallery.html`, `tips.html`, `contacts.html` — сторінки сайту
- `css/`, `images/` — стилі та зображення
- `docs/` — матеріали для звіту: опис роботи (`README_dlya_zvitu.md`), макет сторінки (`wireframe.png`), скріншоти

Тема всіх лаб — DEEP OPS: спорядження для довготривалого дайвінгу та прилади нічного бачення. Навчальний проєкт; сайт не пов'язаний з підрозділами, згаданими на сторінках.
